# API Restful para Gerenciamento de Estoque

API desenvolvida em **Java** com **Spring Boot** para gerenciamento e controle de estoque de produtos,utilizando **SQLite** para persistência de dados

Este projeto é uma evolução em arquitetura web do projeto anterior de gerenciamento de estoque via CLI.

---
## Tecnologias

- **Java 17**
- **Spring Boot 4.1.1**
- **Spring Data JPA**
- **SQLite**
- **Maven**

--- 
## Como Executar

### Pré-Requisitos
 - Java 17 ou superior
 - Git 
### Passo a Passo
1. Clone o Repositório

````bash 
git clone https://github.com/danilo062/estoque-spring-boot
```` 
2. Abra o projeto na sua IDE
3. Aguarde o Maven carregar as dependências
4. Execute a classe EstoqueApiAplication.java
5. A API está rodando em http://localhost:8080
